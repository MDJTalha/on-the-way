# Pi Next Hackathon Plan

## Project submission concept

**Global On the Way — Real-world mobility, powered by Pi.**

A Pi Browser application where a Pioneer can authenticate, request a ride, compare driver offers, follow the trip lifecycle and complete a Pi Testnet payment verified by the backend.

## Core judging demonstration

1. Open the application in Pi Browser.
2. Authenticate through the official Pi SDK.
3. Enter pickup and destination.
4. Choose car, bike or rickshaw.
5. Review suggested fare or submit an offer.
6. Switch to a driver account and accept/counter the request.
7. Confirm assignment and trip state transitions.
8. Execute a Testnet payment.
9. Show backend verification and reconciled booking/payment records.
10. Explain the expansion path to intercity, freight, food, grocery and retail.

## Submission assets

- Working Pi Browser demo.
- Testnet app configuration and integration evidence.
- Source repository and setup instructions.
- Architecture and security documentation.
- Five-minute demo video.
- Screenshots and product walkthrough.
- Clear list of implemented versus planned functionality.
- Test evidence and known limitations.

## Rules checklist

Before submitting, verify the official Pi Next rules for eligibility, team requirements, deadlines, categories, required SDK/API usage, Mainnet/Testnet requirements, intellectual property, judging criteria and submission format. Do not assume eligibility or deadlines based on summit dates alone.

## Integrity rules

- Do not fabricate users, drivers, rides, transactions or traction.
- Label simulated data clearly.
- Do not claim live navigation until a real map provider is configured.
- Do not claim completed Pi payments until backend verification succeeds.
- Do not imply official Pi Network endorsement.
